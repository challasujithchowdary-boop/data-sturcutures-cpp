
# Data Structures Implementation in C++

## Student Project

This project implements two fundamental data structures
using C++.

## Data Structures Implemented

1. Singly Linked List
2. Binary Search Tree (BST)

---

## 1. Singly Linked List

The linked list supports the following operations:

- Insert
- Delete
- Search
- Display

### Complexity Analysis

| Operation | Time Complexity |
|---|---|
| Insert | O(n) |
| Delete | O(n) |
| Search | O(n) |
| Display | O(n) |

Space Complexity: O(n)

---

## 2. Binary Search Tree

The Binary Search Tree supports:

- Insert
- Delete
- Search
- Inorder Traversal

### Complexity Analysis

| Operation | Average Case | Worst Case |
|---|---|---|
| Insert | O(log n) | O(n) |
| Delete | O(log n) | O(n) |
| Search | O(log n) | O(n) |

Inorder Traversal: O(n)

Space Complexity: O(n)
